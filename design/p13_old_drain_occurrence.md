# P13 — Old Drain Opens

`old_drain_opens` is one bounded rare occurrence for Open Yard Net recovery after wave two. Eligibility is deterministic from the run seed and stable event stream: one slot out of three seeds is selected.

The event offers two safe choices. Seal the drain or mark it as an emergency escape route. Both choices set a visible run flag and preserve all existing counters; neither changes combat math in this slice.

Acceptance requires identical selection for identical seeds, variation across three consecutive seeds, save/load persistence, two legal choices, visible Ledger/Results consequences, UI smoke, and a 1280×720 checkpoint. This is not a general weighted scheduler.
